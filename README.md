# Executive Sales Dashboard

An interactive Executive Sales Dashboard developed using Microsoft Power BI to analyze sales performance and present key business metrics through clear and interactive visualizations.

## Project Overview

This project was developed to transform sales data into an interactive business intelligence dashboard that enables users to monitor overall performance, explore sales trends, and identify important patterns across different business dimensions.

The dashboard is designed to provide a concise executive-level overview while allowing users to interact with the report through filters and visual elements.

## Key Features

- Interactive sales performance dashboard
- Executive-level KPI monitoring
- Sales trend analysis
- Performance comparison across different categories
- Interactive filters and slicers
- Business-focused data visualization
- Dynamic report exploration using Power BI

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization
- Business Intelligence

## Project File

The Power BI project file is available in this repository:

`Executive Sales Dashboard.pbix`
